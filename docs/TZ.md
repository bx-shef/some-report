## 1. Цель отчёта

Предоставить руководителю полную аналитику по лидам: от поступления до закрытия сделки, с оценкой
эффективности источников, работы менеджеров и причин потерь.

## 2. Период и фильтры

Период: день / неделя / месяц / квартал / произвольный.

Фильтры: источник, менеджер, статус лида, причина закрытия лида, причина брака сделки.

| Блок | Показатели |
|---|---|
| Сводка (KPI) | Всего лидов, брак (кол-во/%), квалифицировано в сделку (кол-во/%), успешные сделки (кол-во/%), выручка (BYN), конверсия лид→сделка, конверсия лид→сделка «успех» |
| Воронка | Диаграмма: Лиды → Квалифицировано → Успешные сделки (с % по каждому этапу) |
| Обработка лидов | Обработанные, необработанные/просроченные, среднее время первого ответа (в т.ч. по источникам) |
| Брак лидов | Причины закрытия: дубли, спам, нецелевой запрос, сервисное обращение (кол-во и %) |
| Проигранные сделки | Причины проигрыша, кол-во сделок, сумма потерянной выручки по каждой причине |
| Потери до сделки | Кол-во лидов, не дошедших до сделки, и причины |
| Эффективность источников | Таблица по каждому источнику: лиды, брак, квалифицировано, конверсия в сделку (%), успешные продажи, выручка, конверсия в продажу (%) |
| Топ-5 источников | По количеству лидов |

## 3. Пояснения по блокам

### Сводка KPI

| Показатель | Формула |
|---|---|
| Всего лидов | Количество всех созданных лидов |
| Брак | Дубли + Спам + Нецелевые + Сервисные |
| Брак, % | Брак / Всего лидов × 100 % |
| Квалифицировано в сделку | Количество лидов, по которым создана/связана сделка |
| Конверсия в сделку | Квалифицировано / (Всего лидов − Брак) × 100 % |
| Успешные сделки | Количество сделок со статусом «Успешно» |
| Конверсия в продажу | Успешные сделки / (Всего лидов − Брак) × 100 % |
| Выручка | Сумма успешных сделок |

### Воронка

Лиды → Квалифицировано → Успешные сделки.

Для каждого этапа: количество + % от качественных лидов.

### Обработка лидов

Выводить: обработанные; необработанные; просроченные; % необработанных; % просроченных; среднее
время первого ответа; среднее время ответа по источникам.

Среднее время ответа: Σ(время от создания лида до первого действия) / количество обработанных
лидов.

### Брак лидов

Причины: дубль; спам; нецелевой запрос; сервисное обращение.

По каждой причине: количество + % от всех лидов + % от общего брака.

### Потери до сделки

Количество: Всего лидов − Брак − Квалифицировано.

Выводить: количество; % от качественных лидов; причины; количество и % по каждой причине.

### Проигранные сделки

Только сделки со статусом «Проиграна».

По каждой причине: количество; % от проигранных; потерянная выручка; % потерянной выручки.

Потерянная выручка = сумма проигранных сделок.

### Эффективность источников

Таблица по каждому источнику: Источник | Лиды | Брак | Брак % | Квалифицировано | Конверсия в
сделку | Успешные | Выручка | Конверсия в продажу.

Формулы:

- Брак % = Брак / Лиды × 100 %
- Конверсия в сделку = Квалифицировано / (Лиды − Брак) × 100 %
- Конверсия в продажу = Успешные / (Лиды − Брак) × 100 %

### Топ-5 источников

5 источников с максимальным количеством лидов.

Показатели: лиды, брак %, квалифицировано, конверсия в сделку, успешные, выручка, конверсия в
продажу.
